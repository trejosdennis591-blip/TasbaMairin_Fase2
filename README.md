# TasbaMairin

## Descripción

TasbaMairin es una aplicación móvil desarrollada con Flutter que tiene como objetivo facilitar la compra, venta e intercambio de productos entre mujeres emprendedoras y comunidades rurales, indígenas y afrodescendientes.

Actualmente el proyecto se encuentra en fase de desarrollo y cuenta con un prototipo funcional.

## Propósito del proyecto

El propósito de TasbaMairin es ofrecer una plataforma sencilla e intuitiva que permita a los usuarios publicar, buscar e intercambiar productos, fortaleciendo el comercio local y promoviendo el emprendimiento comunitario.

## Tecnologías utilizadas

- Flutter
- Dart
- Visual Studio Code
- Android Studio

## Requisitos

Antes de ejecutar el proyecto es necesario tener instalado:

- Flutter SDK
- Visual Studio Code o Android Studio
- Un emulador Android o un dispositivo físico

## Instalación

1. Clonar o descargar el proyecto.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Instalar las dependencias ejecutando:

```bash
flutter pub get
```

## Ejecución

Para iniciar la aplicación, ejecutar en la terminal:

```bash
flutter run
```

## Estado actual del proyecto

Actualmente el prototipo incluye las siguientes pantallas:

- Inicio de sesión.
- Registro de usuarios.
- Pantalla principal (Home).
- Pantalla de búsqueda.

En futuras versiones se implementarán funcionalidades como:

- Mensajería entre usuarios.
- Perfil de usuario.
- Publicación de productos.
- Conexión con una base de datos MySQL.
